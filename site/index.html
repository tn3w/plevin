Install

Two readers, one file

The same fields in Python and JavaScript, field for field, both reading the memory-mapped database with no service in between.

  • Python 3.10+, no dependencies on 3.14
  • ESM for Node, Deno, Bun, Workers and the browser
  • The database ships as a wheel, or as a file you host
  • Air-gapped: no address ever leaves the process
# pip install "plevin[db,full]"
import plevin

found = plevin.lookup("1.1.1.1")
found.place.city.name        # 'Brisbane'
found.network.operator.brand # 'Cloudflare'
found.abuse.risk             # 0.98 on a tor exit

found = plevin.lookup("1.1.1.1", dns=True)
found.dns.hostname           # 'one.one.one.one'
// npm install plevinjs
import { open } from "plevinjs/node";

const db = await open("plevin.plv");
db.lookup("1.1.1.1").network.operator.brand;
db.lookup("1.1.1.1").place.country.flag;

const named = await db.resolve("1.1.1.1", { dns: true });
named.dns.hostname;  // 'one.one.one.one'

Questions

      
What a lookup is, and is not


      

        

          
Does the address I type leave the tab?

          
The lookup does not: the database file is downloaded once and every answer is
            read out of it here. Three things on this page do call out -
            api.ipify.org behind My address, and
            cloudflare-dns.com and dns.google over
            DNS-over-HTTPS for the DNS card, and CARTO for the map tiles. The
            libraries ask none of those unless a dns flag says so.

        

        

          
What does a lookup return?

          
98 fields: city, region, country, coordinates, postal code and timezone;
            ASN, operator, announcement, RPKI state and abuse mailbox; and abuse records
            with an address risk and a network risk score.

        

        

          
Is there an API, and does it need a key?

          
Yes, plevin.tn3w.dev/api answers the same JSON with no key, no
            rate limit and CORS open to every origin. You can also run the worker on your
            own account.

        

        

          
How often is the database rebuilt?

          
Daily, from MaxMind GeoLite2, IP2Location LITE, GeoNames, Natural Earth, a
            RIPE RIS RIB, RPKI ROAs, the NRO delegations, CAIDA, PeeringDB and 156 abuse
            feeds.

        

        

          
What can I type into the box?

          
Any IPv4 or IPv6 address. A hostname works too: it is resolved to an address
            over DNS first, then looked up in the file like any other.

        

        

          
How exact is the location?

          
City level at best, and every place carries its own confidence and radius in
            kilometres. An IP address names a network, not a person or a street, so treat
            the coordinates as the centre of an area.
